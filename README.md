# Ent303 Rise

一个 macOS 桌面小工具，解决久坐问题：记录连续工作时长，到点提醒你起来活动，并给一条具体建议。

## 当前状态：可测的 MVP

**两种提醒方式，在设置里切换：**

| 方式 | 判断依据 |
|---|---|
| **自动检测**（默认） | 读取系统空闲时长，无需任何权限。空闲 ≤ 2 分钟算在工作，≥ 5 分钟算已离开并清零 |
| **手动确认** | 两个图标手动声明：点「在电脑前」开始计时，点「去活动」停止并清零 |

**其它已实现：**

- ✅ 提醒间隔可调（1–120 分钟），两种方式共用
- ✅ 连续工作计时、进度条、距下次提醒的倒计时
- ✅ 12 条建议池，随机且不连续重复
- ✅ 菜单栏常驻：显示/隐藏、立即提醒、退出
- ✅ 无 Dock 图标，透明悬浮窗，可拖动

## 运行

```bash
./build.sh
open build/Ent303_Rise.app
```

需要 macOS 13+ 和 Command Line Tools。不需要完整 Xcode。

> 本机 `swift build`（SwiftPM）因 CLT 与 SDK 版本错位会 abort，
> 所以 `build.sh` 直接调用 `swiftc` 并显式指定一个匹配的 SDK。

## 怎么测

1. 打开 app，屏幕右下角出现悬浮窗
2. 默认是**自动检测**模式，头部应显示「正在电脑前工作（空闲 N 秒）」并开始计时
3. 把「提醒间隔」调成 **1 分钟**，等 1 分钟看提醒是否弹出
4. 或者点 **预览提醒** 立刻看一条
5. 点 **我起来了** → 提醒关闭、计时归零
6. 切到 **手动确认** → 出现两个图标，手动切换状态
7. 什么都不动等 5 分钟 → 自动模式应显示「检测到你已离开，计时已清零」
8. 菜单栏有个站立小人图标，可以隐藏窗口 / 退出

调试参数：

```bash
open build/Ent303_Rise.app --args --demo-reminder   # 启动 1 秒后自动弹一条提醒
```
