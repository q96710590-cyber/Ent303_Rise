# Ent303 Rise

一个 macOS 桌面小工具，解决久坐问题：记录连续工作时长，到点提醒你起来活动，并给一条具体建议。

## 当前状态：MVP 骨架

这是**第一步的最小可测版本**，刻意做了简化：

- ❌ 还没做自动检测（不读系统空闲时间）
- ✅ 用**两个图标手动确认**：点「在电脑前」开始计时，点「去活动」停止并清零
- ✅ 连续工作倒计时、进度条、到点弹出建议
- ✅ 12 条建议池，随机且不连续重复
- ✅ 菜单栏常驻，可显示/隐藏、手动触发提醒、退出
- ✅ 无 Dock 图标，透明悬浮窗，可拖动

## 运行

```bash
./build.sh
open build/Ent303_Rise.app
```

需要 macOS 13+ 和 Command Line Tools（`xcode-select --install`）。不需要完整 Xcode。

## 怎么测

1. 打开 app，右下角出现悬浮窗
2. 点 **在电脑前** → 计时开始
3. 把「提醒间隔」调成 **1 分钟**，等 1 分钟看提醒是否正常弹出
4. 或者直接点 **测试提醒** 立刻预览
5. 点 **我起来了** → 提醒关闭、计时归零
6. 点 **去活动** → 计时暂停并清零
7. 菜单栏有个小人图标，可以隐藏窗口 / 退出
