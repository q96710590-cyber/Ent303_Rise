# RISE 小猫陪练 · Windows 版

在这台电脑上，双击 `启动小游戏.cmd` 或项目根目录的 `Start_RISE_Windows.cmd` 即可打开。

## 跟练

1. 选择向上伸展、双臂侧平举、双臂弯举中的一项或多项，选择 1–20 组。每组完整完成所选动作，每个动作 3 次，自动获得 5 金币。
2. 点击「开启摄像头」。默认设备编号为 0；如使用其他摄像头，关闭后可换编号。
3. 轻松模式只要求双肩和双手可见，坐着或站着都能做，肘部和髋部可以不入镜。连续稳定入镜约 0.5 秒后自动开始，无需点击开始按钮。单纯入镜不会获得金币。
4. 按照小猫提示：双手略放低并稳定约 0.15 秒 → 抬到大致位置保持约 0.25 秒 → 再放低约 0.15 秒。不要求伸直、严格肩高或标准肘部角度；允许左右不齐。仍需完成抬起再放下的循环。
5. 可暂停、继续或提前结束。手动暂停后仍需点击「继续跟练」，避免自动恢复打断休息。已完成组的金币即时保存，未完成的一组不奖励。完成所选组数时自动释放摄像头；不会无限重新开始。要再练一轮，点击「再练一轮」后重新开启摄像头即可。

金币和背包保存在 `data/rise.sqlite3`，首次余额为 20，关闭应用不会重置。商店使用原项目的四类素材，每件价格为 1 金币；食物和植物可重复购买，小床和配饰每件限购一次。Windows 钱包独立于 macOS 版。

## 版本范围

这是运动小游戏、金币钱包、商店和背包的 Windows 原生窗口。原 macOS 源码仍保留，原有桌面悬浮宠物、系统空闲久坐提醒和番茄钟尚未迁移到 Windows。

窗口复用补充素材包中的摇尾小猫及金币动画；动画旁有随所选动作变化的示意。关节点置信度门槛从 0.45 降为 0.25；人体检测、存在和跟踪门槛设为 0.35。只用双肩双手判定动作，肘部和髋部仅在可见时绘制。短暂抖动约 0.35 秒、丢失约 0.7 秒内保留动作阶段，不会把缺失时间算作保持；长时间丢失、多人、过期帧仍不计数。暂停、切换到商店或摄像头中断会重置当前未完成的动作循环。

## 运行环境

此电脑已存在的 `ent/code/.venv` 提供 Python 3.12、PySide6、OpenCV 和 MediaPipe，启动器自动使用。模型已复制到本目录的 `models/`，不需要网络。无需修改旧的 `code/app`。

若移到其他电脑，在 Windows 本目录准备 Python 3.12 环境：

```powershell
py -3.12 -m venv .venv
.venv\Scripts\python.exe -m pip install -r requirements.txt
.venv\Scripts\python.exe app.py
```

姿态检测使用 MediaPipe Tasks 的本地视频推理接口，参考[官方 Python 说明](https://developers.google.com/edge/mediapipe/solutions/vision/pose_landmarker/python)。画面不保存、不上传。模型来源和校验值见 `models/SOURCE.md`。
